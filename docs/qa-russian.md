# QA: русская локализация CryptoWatch

Автоматическая проверка: npm run build && npm test. В tests/specs/ есть
диалоги для приветствия, помощи, пустого списка, настроек, проверки цены и
dashboard; они проверяют точный русский текст ответов.

Ручная проверка в личном чате:

1. Отправить /start или /menu: приветствие должно содержать только inline-кнопки «🛍 Каталог», «Список наблюдения», «Оповещения», «Проверить цену» и «Настройки». Внизу чата не должно появляться постоянной клавиатуры.
2. Нажать каждую кнопку меню: открывается соответствующий экран редактированием сообщения. На каждом экране проверить «⬅️ Назад» — она возвращает в inline-меню.
3. Открыть «Добавить монету», выбрать BTC или ввести тикер и проверить
   подтверждение, кнопки списка и уведомлений.
4. Открыть уведомление по цене, ввести сумму, выбрать «Выше цели» или «Ниже
   цели», затем проверить русское подтверждение.
5. Создать уведомление по проценту, выбрать процент и окно времени; проверить
   русское описание сохранённого правила.
6. Выполнить /price и /price BTC: цены, дата в формате dd.MM.yyyy HH:mm,
   источник и ошибки должны быть на русском.
7. В «Настройках» задать тихие часы и включить утренний обзор; проверить
   русские подтверждения и текст сводки.
8. Симулировать срабатывание уведомления и убедиться, что уведомление
   содержит тикер, старую и новую цену, изменение, тип и время на русском.
9. Владелец отправляет /dashboard: метрики, ошибки и кнопки управления
   должны быть на русском. Для незаданного ADMIN_CHAT_ID проверить понятное
   сообщение о том, что доступ владельца ещё не настроен.
